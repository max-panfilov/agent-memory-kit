# Roadmap

Пункты ниже — направления развития, а не реализованные возможности и не сроки.

## Локальное ранжирование

Добавить отдельный профиль с локальными embeddings и reciprocal-rank fusion. Сохранить лексический режим по умолчанию, границы запроса, доказательства повторного построения и честное обозначение типа score.

## Асинхронная обработка

Добавить transactional outbox, durable claims и ограниченный spool для восстановления после сбоя процесса. Обязательные проверки: lost COMMIT ACK, crash, revocation, epoch fencing, queue depth, oldest pending и retention.

## Mem0 и Qdrant

Добавить отключаемый профиль извлечения фактов. Внешний LLM должен требовать явного согласия на передачу содержимого. Результаты поиска по-прежнему гидратируются из канонических событий.

## Sleep

Добавить конфигурируемые краткие сводки с двумя полными чтениями источника, неизменными ревизиями, reviewer gate и `stale`. Сводка остаётся производной и не заменяет brief или timeline.

## Производственные адаптеры

Добавить отдельные адаптеры для существующих реестров и бэкендов без изменения базового контракта. Не переносить студийные схемы, финансовые команды, регистрацию проектов или частные полномочия в ядро.

## Эксплуатация

Добавить персональные области, rate limits, метрики, алерты, зашифрованные внешние копии и регулярные restore drills. Любой новый production adapter требует отдельной приёмки и документации ограничений.
