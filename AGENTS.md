# Agent Memory Kit — инструкции для агентов

## Границы

- Сохраняйте ровно восемь публичных MCP-инструментов. Новые возможности сначала обсуждаются отдельно.
- PostgreSQL хранит канонические события и аудит. Локальные файлы содержат только синтетические документы и конфигурацию.
- Не добавляйте Mem0, FastEmbed, Qdrant, Sleep, внешние LLM, Payload или production-интеграции в базовый контур.
- Не помещайте секреты, реальные проектные данные, клиентские выгрузки, частную инфраструктуру или production-журналы в репозиторий.
- Не меняйте семантику UUID, исправлений и неизвестных исходов без новых проверок.

## Изменения

- Код и комментарии — на английском, документация и пользовательские тексты — на русском.
- Для новых утверждений в документации нужна проверка поведения или явная пометка proposal/roadmap.
- Не заявляйте совместимость с конкретным MCP-клиентом без отдельной проверки.
- Не используйте GitHub-hosted runners для сборки и тестов. Запускайте `ci/verify.sh` в доверенной self-hosted среде с Docker.

## Приёмка

Перед PR выполните `ci/verify.sh`, `git diff --check`, `python3 scripts/check_public.py` и вычитку русского текста через `ru-check`. Проверка должна включать реальный MCP smoke и изолированное восстановление PostgreSQL.
