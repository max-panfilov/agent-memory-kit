# Инструкции для агента проекта

## Начало работы и восстановление контекста

1. Определите точный репозиторий, `application_id` и полный Git SHA.
2. Вызовите `get_work_context`, прочитайте обязательные документы через `read_document`, затем получите `get_project_brief`.
3. Для полной истории используйте `get_project_timeline` с пагинацией. Для поиска прошлых решений вызывайте `search_project_memory`, а затем `read_project_memory` и исходные документы.
4. Различайте `proposed`, `observed` и `confirmed`. Запись памяти не разрешает деплой, сообщения или изменение других систем.

## После важного события

Сохраняйте решение, крупную функцию, проверенный релиз, инцидент или передачу работы через `record_project_memory`. Не записывайте каждый шаг, секреты, персональные данные или полную переписку.

- Создайте UUID один раз и сохраните его с точной полезной нагрузкой вне Git.
- Укажите время с часовым поясом и ссылки `kind`/`ref` на источники.
- После неизвестного исхода сначала вызовите `read_project_memory` с тем же UUID.
- Повторяйте только тот же UUID и полезную нагрузку. Исправление оформляйте новым событием `correction` со ссылкой `supersedes_id`.
- Подключение MCP не гарантирует, что агент прочитает инструкции или запишет итог. Проверяйте это в рабочем процессе.
