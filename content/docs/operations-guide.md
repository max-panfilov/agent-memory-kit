# Операционный путеводитель

Статус observed для синтетического примера.

Перед записью сохраните UUID и точную полезную нагрузку вне Git. После неизвестного исхода прочитайте событие по исходному UUID через read_project_memory. Не создавайте новый UUID автоматически: повтор мог бы создать второй эффект.

Проверка резервной копии включает чтение манифеста и восстановление в отдельную пустую базу. Наличие таймера или файла дампа само по себе не подтверждает успешное восстановление.
